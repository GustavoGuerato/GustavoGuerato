## Projeto principal: AccessForge

API multi-tenant de autenticação e autorização, com frontend em React.

- **[workspace_auth](https://github.com/GustavoGuerato/workspace_auth)**: Node.js, TypeScript, Express e PostgreSQL com SQL puro. JWT de acesso, refresh token rotativo (só o hash SHA-256 fica no banco), papéis por workspace via membership (RBAC), validação com Zod, testes com Jest + Supertest, incluindo isolamento entre tenants.
- **[AccessForge_WEB](https://github.com/GustavoGuerato/AccessForge_WEB)**: React 19 + TypeScript + Vite. Sessão restaurada via cookie HttpOnly, access token só em memória, estados de requisição modelados como união discriminada.

Os READMEs documentam decisões técnicas, trade-offs e limitações conhecidas.
